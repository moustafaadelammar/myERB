# myERB — نظام إدارة الشركة

نظام ERP عربي RTL مبني بـ React + Vite.

الوحدات: Dashboard، المبيعات، المشتريات، المخزون، العملاء، الموردين، المالية، التقارير، الإعدادات.

التشغيل: npm install ثم npm run dev.

البيانات التجريبية تحفظ محلياً كبداية، مع تجهيز المشروع للتوسع إلى قاعدة بيانات وصلاحيات وAuthentication.
